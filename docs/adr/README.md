# Architecture Decision Records

One short file per decision that would otherwise be re-litigated every few months.
Name them `NNNN-short-title.md`.

Format: **Context** (what forced the decision) / **Decision** (what we chose) /
**Consequences** (what this costs us, and what would make us revisit).

Worth recording: why RunPod over a managed inference provider, why Unsloth over
Axolotl, why HF over an internal artifact store, why a given base model.
